# 가치사슬 분석 — 의류 및 패션 산업
### (예시 기업: 나이키, 자라)

`예시_토스_카카오페이.md`의 형식을 따라, 스포츠웨어 브랜드(나이키)와 패스트패션 SPA 브랜드(자라)의 가치사슬을 비교합니다.

## 1. 주요활동 적용 예시표

### 1-1. 나이키

| 주요활동 | 가치사슬 **설계 적용 예시** 🏗️ | 가치사슬 **개선 적용 예시** 🚀 |
| --- | --- | --- |
| **투입·조달 물류** | • 베트남·인도네시아 등 글로벌 OEM 네트워크에서 대량생산 소싱을 확보한다.<br>• 자체 R&D로 신소재(플라이니트, 에어 등)를 개발해 투입한다.<br>• 자체 디자이너·스포츠과학 인력을 통해 제품 컨셉을 확보한다. | • OEM 공급업체 다변화로 특정 국가·업체 의존도를 낮춘다.<br>• 신소재 개발 리드타임을 단축한다.<br>• 원자재(면화 등) 가격 변동에 대한 헤지 전략을 강화한다. |
| **운영·생산** | • 시즌 단위 대형 배치생산으로 규모의 경제를 확보한다.<br>• 글로벌 품질기준에 따른 표준화된 생산 프로세스를 운영한다. | • 소량 생산 라인을 병행해 트렌드 대응 속도를 높인다.<br>• 생산 데이터를 수요예측 모델에 반영해 재고 리스크를 줄인다. |
| **산출·배송 물류** | • 글로벌 물류센터를 통해 도매·리테일 채널에 유통한다.<br>• 온라인 직배송(D2C, Nike App/웹)을 확대한다. | • D2C 물류 리드타임을 단축해 오프라인 대비 경쟁력을 높인다.<br>• 재고를 지역별로 최적 배분해 품절·과잉재고를 줄인다. |
| **마케팅 및 영업** | • 스타 운동선수 스폰서십과 브랜드 스토리텔링으로 소비자에게 어필한다.<br>• Nike App/멤버십으로 직접 고객관계를 구축한다. | • 스폰서십 마케팅비 대비 매출전환 효과를 정교하게 측정한다.<br>• 멤버십 데이터를 활용해 개인화 추천의 정확도를 높인다. |
| **서비스** | • 멤버십 기반 개인화 서비스와 앱 내 트레이닝 콘텐츠를 결합한다. | • 반품·교환 절차를 간소화해 온라인 구매 장벽을 낮춘다.<br>• 고객 피드백을 신제품 개발 사이클에 신속히 반영한다. |

### 1-2. 자라 (인디텍스)

| 주요활동 | 가치사슬 **설계 적용 예시** 🏗️ | 가치사슬 **개선 적용 예시** 🚀 |
| --- | --- | --- |
| **투입·조달 물류** | • 스페인·포르투갈·모로코 등 근거리(니어쇼어) 생산기지를 확보해 리드타임을 최소화한다.<br>• 색상·패턴을 미확정한 원단을 사전 비축해 트렌드 대응 유연성을 확보한다. | • 매장 판매데이터를 실시간으로 원단 사전비축 계획에 반영한다.<br>• 근거리 생산기지의 비중을 확대해 아시아 소싱 대비 리드타임 우위를 유지한다. |
| **운영·생산** | • SPA(자체기획·생산·유통) 모델로 소량 다품종을 생산한다.<br>• 2주 단위 신상 출시로 빠른 생산-판매 사이클을 운영한다. | • RFID 기반 재고관리로 매장별 재고 정확도를 높인다.<br>• 판매 초기 반응을 즉시 후속 생산량 조정에 반영한다. |
| **산출·배송 물류** | • 항공물류를 활용해 매장에 신속 배송한다(리드타임 단축이 핵심 경쟁력).<br>• 매장 자체를 물류 허브처럼 운영해 온라인 주문을 매장에서 처리한다. | • 항공물류 비용과 리드타임 단축 효과의 균형을 지속적으로 최적화한다.<br>• 온라인-매장 통합 재고 가시성을 높인다. |
| **마케팅 및 영업** | • 광고를 최소화하고 매장 위치(프라임 로케이션)와 진열 자체를 마케팅 수단으로 활용한다.<br>• "지금 없으면 다음엔 없다"는 희소성 마케팅으로 구매를 유도한다. | • 매장 방문 유도 효과를 온라인 트래픽과 연계해 측정한다.<br>• 희소성 마케팅이 과도한 재고 회전율 압박으로 이어지지 않는지 점검한다. |
| **서비스** | • 온라인 반품 절차를 간소화하고 매장 내 빠른 교환·환불을 제공한다. | • 반품 데이터를 사이즈·핏 문제 등 상품기획 개선에 활용한다. |

## 2. 지원활동 적용 예시표 (요약)

| 지원활동 | 나이키 | 자라 (인디텍스) |
| --- | --- | --- |
| **기업 인프라** | 글로벌 브랜드 관리 조직, 지역별 법인 운영 | 인디텍스 그룹 내 여러 브랜드(자라·마시모두띠 등) 포트폴리오 관리 체계 |
| **인적자원 관리** | 디자인·마케팅·스포츠과학 인재 중심 조직 | 디자이너-생산 간 밀착 커뮤니케이션이 가능한 빠른 의사결정 조직구조 |
| **기술 개발** | 소재 R&D(에어, 플라이니트 등 특허기술), 데이터 기반 수요예측 | RFID 기반 재고관리, 매장 판매데이터→생산 피드백 시스템(핵심 기술자산) |
| **조달·구매** | 글로벌 대량구매를 통한 원가절감, 아시아 OEM 네트워크 관리 | 근거리 생산기지 확보로 리드타임 최소화, 원단 사전 확보 전략 |

| **핵심 원가우위** | 글로벌 대량생산에 따른 규모의 경제 | 근거리 생산 + 소량 다품종으로 재고비용 최소화 |
| **차별화 원천** | 브랜드력(스타 마케팅), 소재 R&D 기술특허 | 초단기 생산-판매 사이클(리드타임), 매장 자체가 마케팅 |
| **핵심 병목** | 신소재 개발과 대량생산 리드타임 | 항공물류 비용, 근거리 생산기지의 생산능력 한계 |
| **기술 경쟁력** | 소재/제품 기술(R&D) | 공급망/재고관리 기술(RFID, 수요반영 속도) |
