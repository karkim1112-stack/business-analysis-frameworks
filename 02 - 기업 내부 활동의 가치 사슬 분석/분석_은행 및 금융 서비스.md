# 가치사슬 분석 — 은행 및 금융 서비스 산업
### (예시 기업: KB국민은행, 카카오뱅크)

`예시_토스_카카오페이.md`의 형식을 따라, 전통 시중은행(KB국민은행)과 인터넷전문은행(카카오뱅크)의 가치사슬을 비교합니다.

## 1. 주요활동 적용 예시표

### 1-1. KB국민은행

| 주요활동 | 가치사슬 **설계 적용 예시** 🏗️ | 가치사슬 **개선 적용 예시** 🚀 |
| --- | --- | --- |
| **투입·조달 물류** | • 전국 지점망을 통해 저원가 예수금을 확보한다.<br>• 카드·증권·보험 등 KB금융그룹 계열사 고객데이터를 연계한다.<br>• CB사(신용정보회사)의 신용평가 데이터를 조달한다.<br>• 오픈뱅킹·마이데이터 API로 타행 계좌정보를 연결한다. | • 계열사 간 중복 수집되는 고객정보를 통합·표준화한다.<br>• 레거시 코어뱅킹 시스템의 데이터 정합성을 개선한다.<br>• 외부 신용평가 데이터에 대한 의존도를 낮출 대안신용평가 모델을 개발한다.<br>• 오픈뱅킹 API 장애 시 대체 조회 경로를 마련한다. |
| **운영·생산** | • 대면 심사(지점)와 비대면 채널(앱)을 병행해 계좌개설·대출을 처리한다.<br>• 방대한 대출 포트폴리오를 리스크 등급별로 심사·운용한다.<br>• 대규모 거래량을 24시간 안정적으로 처리하는 코어뱅킹 시스템을 운영한다. | • 대면 심사 의존 비율을 낮추고 비대면 처리 비중을 확대한다.<br>• 대출 심사 소요시간을 단축한다.<br>• 이상거래 탐지 정확도를 높여 오탐률을 줄인다.<br>• 레거시 시스템의 배포 속도와 안정성을 동시에 개선한다. |
| **산출·배송 물류** | • 창구·인터넷뱅킹·앱을 통해 거래결과와 상품 안내를 전달한다.<br>• 계열사 상품(카드·보험·펀드)을 앱 내 배너·상담으로 안내한다. | • 종이서류·도장 등 잔존 오프라인 절차를 디지털로 전환한다.<br>• 다수 계열사 알림을 통합해 과도한 알림을 줄인다.<br>• 복잡한 금융상품의 조건을 비교 가능한 형식으로 제공한다. |
| **마케팅 및 영업** | • 오프라인 지점·TV광고로 신뢰·안정성 브랜드 이미지를 구축한다.<br>• 계열사 교차판매(카드·증권·보험)로 고객당 매출을 확대한다. | • 지점 방문 없이 완결되는 디지털 가입 여정을 확대한다.<br>• 젊은 고객층 유치를 위한 디지털 마케팅 비중을 높인다.<br>• 교차판매 성과를 단기 가입 실적이 아닌 고객 적합성 기준으로 평가한다. |
| **서비스** | • 지점 상담원과 콜센터를 통한 대면 민원 처리 체계를 운영한다.<br>• 금융사고(보이스피싱 등) 발생 시 조사·보상 절차를 수행한다. | • 챗봇·AI 상담 비중을 늘려 단순 문의 처리속도를 높인다.<br>• 반복 민원의 원인을 상품·시스템·정책 문제로 분류해 근본 개선한다. |

### 1-2. 카카오뱅크

| 주요활동 | 가치사슬 **설계 적용 예시** 🏗️ | 가치사슬 **개선 적용 예시** 🚀 |
| --- | --- | --- |
| **투입·조달 물류** | • 카카오톡의 기존 이용자 트래픽을 저비용 고객 유입 자원으로 활용한다.<br>• 오픈뱅킹·마이데이터 API로 타행 계좌정보를 연결한다.<br>• 자체 서버 대신 클라우드 인프라에 의존해 인프라를 확보한다. | • 카카오 생태계 데이터를 활용한 대안신용평가 모델의 정교도를 높인다.<br>• 특정 클라우드 벤더에 대한 의존도를 낮출 이중화 전략을 마련한다.<br>• 오픈뱅킹 API 장애에 대비한 대체 처리 경로를 확보한다. |
| **운영·생산** | • 100% 비대면 계좌개설·대출 프로세스를 설계한다.<br>• 자체 개발한 대안신용평가모형으로 대출을 심사한다.<br>• 실시간 AI 기반 이상거래 탐지 체계를 운영한다. | • 비대면 심사의 부실률과 승인률 사이 균형을 지속적으로 조정한다.<br>• 이상거래 탐지율을 높이면서 정상거래 오탐을 줄인다.<br>• 거래량 급증(이벤트, 마케팅) 시에도 시스템 안정성을 확보한다. |
| **산출·배송 물류** | • 앱 UI로 승인결과·이자·수수료를 즉시 시각화한다.<br>• 카카오톡 알림과 연동해 거래결과를 전달한다. | • 대출상품 비교 정보를 총상환액 등 실질 비용까지 포함해 제공한다.<br>• 앱과 카카오톡 알림의 중복을 줄인다. |
| **마케팅 및 영업** | • 카카오 생태계 트래픽을 그대로 활용해 CAC(고객획득비용)를 낮춘다.<br>• 캐릭터·이모티콘 마케팅으로 젊은 세대에 어필한다. | • 카카오 트래픽에서 유입된 고객의 장기 유지율을 별도로 분석한다.<br>• 저원가 유입 우위를 자산관리·투자 등 고마진 서비스 교차판매로 확장한다. |
| **서비스** | • 챗봇과 비대면 상담센터로 24시간 셀프서비스를 지향한다. | • 챗봇 상담의 잘못된 금융 안내를 방지하는 검증체계를 강화한다.<br>• 전문상담이 필요한 사고·분쟁을 신속히 상담원에게 이관한다. |

| **인적자원 관리** | 전통적 금융 전문인력 중심의 조직문화와 인사체계 | 금융 전문성과 IT 개발 역량을 결합, 스타트업식 조직문화 지향 |
